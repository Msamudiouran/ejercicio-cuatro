# Layout Ejercicio Cuatro - Tema Galería de Arte

La estructura de la página ocupa el **100% de ancho** y **100vh de alto**. Ahora está maquetada **exclusivamente usando Flexbox y Box Model**.

## Medidas y Proporciones:

- **Contenedor Principal (body):**
  - Ancho: `100%`
  - Alto: `100vh`
  - Comportamiento: `display: flex; flex-wrap: wrap;` (permite que los bloques caigan a la siguiente línea al completar el 100% de ancho).

- **Fila 1 (Suma 100% ancho, Alto: 15vh):**
  - **Header**: Ancho `100%`, Alto `15%`.

- **Fila 2 (Suma 100% ancho, Alto: 65vh):**
  - **Imagen Principal (Hero)**: Ancho `60%`, Alto `65%`.
  - **Información (Texto)**: Ancho `40%`, Alto `65%`.

- **Fila 3 (Suma 100% ancho, Alto: 20vh):**
  - **Miniatura 1**: Ancho `20%`, Alto `20%`.
  - **Miniatura 2**: Ancho `20%`, Alto `20%`.
  - **Miniatura 3**: Ancho `20%`, Alto `20%`.
  - **Footer**: Ancho `40%`, Alto `20%`.
